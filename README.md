## Engineering Focus

These are the frontend engineering areas I work with across my projects:

| Area | What I Build |
|------|-------------|
| **Component Architecture** | Reusable, composable UI primitives with shared design systems |
| **Responsive Design** | Fluid layouts from mobile to desktop with consistent experience |
| **State Management** | Client state (Zustand), server state (TanStack Query), and context patterns |
| **Form Engineering** | React Hook Form + Zod validation with inline error handling |
| **API Integration** | REST APIs with JWT auth, interceptors, cache invalidation, and error boundaries |
| **Authentication** | JWT access/refresh rotation, session management, role-based access control |
| **Performance** | Code splitting, lazy loading, optimized bundles, and virtualized lists |
| **UI Polish** | Animations, transitions, skeleton states, and dark/light theme systems |
| **Deployment** | Vercel, Railway, Render — CI/CD with GitHub Actions |
| **AI Integration** | Multi-provider AI APIs, structured responses, and intelligent workflows |
